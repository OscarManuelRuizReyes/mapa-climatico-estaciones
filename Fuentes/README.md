# Fuentes del proyecto

Esta carpeta reúne los insumos documentales y de datos que utiliza el proyecto.

- `dataset_mapa_clima_demo_2015_2024.csv`: serie mensual demostrativa usada por las gráficas y tablas.
- `estaciones_demo_clima_2015_2024.csv`: catálogo de estaciones, coordenadas y atributos climáticos.
- `branding/2026 Branding board TC.pdf`: referencia oficial de identidad visual de Talento CICY.
- `image.jpeg`: recurso gráfico histórico conservado para revisión; la aplicación resuelve sus imágenes desde las rutas configuradas en `app.py`.

Los archivos CSV contienen datos procesados con fines educativos y demostrativos. No sustituyen una fuente climatológica oficial.
